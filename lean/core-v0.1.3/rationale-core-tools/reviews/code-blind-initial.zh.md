## 代码含义概览

CoreReader 的 Duties 是条件义务：对三个 Aspect 中的每个方面，若任意 supplied applicable 谓词判为适用，则同一主张及依据对应的 examined 关系必须成立。Assessed 完全忽略标签列表，因此标签不影响结果是定义直接决定的。具体示例用编号 7、3 及固定方面建立成立或不成立；编号 4 被拒绝来自 4 ≠ 3，不来自另外定义的相关性关系。

Fact 是五种标记，不含命题公式或逻辑赋值。fixtureConsequence 只有手写的三个语境分支；Consistent 排除同一语境中同一列表的两种布尔极性同时成立。具体定理证明该有限关系上的冲突、删除 notQ 后无负极性分支，以及不同语境不能成为同一语境；没有一般逻辑的演绎闭包或实际撤回过程。

ChangeReported 仅要求列表不等时布尔参数为 false，不含报告内容或行为。列表有序且允许重复；相同列表令蕴含空真。ObservationComplete 要求有限列表包含所有自然数；[0, 1] 在 2 处失败。其余两个定理将这项缺口分别与独立的算术真命题和假全称命题的否定组成合取，没有定义列表对结论的支持关系。

初始 selfAssessmentSamples 是 [1]，proposedPrinciple 是 n + 1 = 2 * n。证明在唯一样本 1 处成立，在 0 处失败；初始编码没有自评算法、评估者或哲学对象。

RationaleReader 的 ServiceState 只是两个自然数字段；direct 和 cachedRead 是纯投影，updateOnly 只写 acknowledged，初始 updateInvalidating 直接返回 (n, n)。这些是纯函数，没有 I/O、并发、失效标志或重新加载协议。具体例子证明 (10, 10) 初始一致，单字段改为 11 后成为 (11, 10)，两个字段直接写为 11 后一致，以及写回原值 10 后一致。

延迟记录独立于状态和更新函数。两个延迟恒为 5、2，预算从 6 改为 3 后，直接延迟不再达标；没有单位、测量或因果关系。namedUniversalTruth 对任意 P 和显式 h : P 直接返回 h，内容仅为 P → P。最后三个定理证明 0 ≤ 1，同时用 2 反驳所有自然数均 ≤ 1；没有语义编码函数或一般形式化忠实性定理。
