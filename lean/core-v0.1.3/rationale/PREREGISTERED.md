# New compact models — registered before Lean authoring

These are new bounded encodings for readable evidence, not unchanged replays of all older projects. Historical Core/Rationale models remain untouched; unretained results do not silently become current results. Inventory all original content, map only explicit selected fragments. No whole philosophical text is expected to be proved.

Core fragments: responsibility quantified over actual applicable aspects of the same claim/grounds pair, independently of labels; domain relation supplied and not self-validating. Preserve empirical/value mixed applicability via concrete claim-aspect fixture and wrong-grounds/reported-label variants. The full articulation, basis quality, proportionality, value criticism and all listed empirical/inferential duties remain unmodeled by this narrower interface; do not label whole Assessment passed. Separate sufficient support from truth using a finite observation set with an explicitly stated universal-coverage sufficiency criterion for all natural inputs; bounded observations cannot establish a universal property, whether the property is actually true or false.

Consistency: whole held-set input to an explicit consequence relation, context/question/polarity; a concrete P, P→Q, ¬Q fixture uses a registered one-step consequence for this case, not a general logical calculus. Joint inconsistency, removal of ¬Q, and opposite judgments under distinct contexts get actual probes. A separate changed-content reporting obligation is an interface, not an assertion a real change was reported.

Reflexivity: concrete arithmetic principle n+1=2*n checked on sample1 can pass while counterexample0 refutes it; evaluating oneself is a separate recorded action. This supplies a relevant finite counterexample to self-assessment alone implying correctness, not a general diagnosis of every system or proof that the normative provision is obeyed.

Rationale R1: actual conditional identity theorem h:P⊢P plus a true coded arithmetic claim and false different prose claim; exact arithmetic counterexample illustrates that a proof of one statement does not prove a different stronger statement. Missing bridge is a modeling finding, not proof that philosophical commitments fail. It is an illustration of the accepted R1 row, never a mathematical proof of every prose correspondence judgment.

Rationale software/L119: ServiceState contains acknowledged and cached natural values; direct read reads acknowledged, cache reads cached; updateOnly changes acknowledged and retains cached. Initial10/10, original latencies5/2,budget6 both acceptable; update11 yields11/10. Original-match plus later-mismatch witnesses failure of global equivalence. Positive invalidating update sets both11; unchanged update10 retains agreement. Withdraw any mapping to method-stage lists. Separate tightened budget3 is a different context, not the original case.

Rationale removal arguments and value/historical/general method effectiveness claims remain source-inventoried but unproved unless a reviewed direct correspondence is available. No Boolean encoding of arbitrary truth values substitutes for an empirical or value argument. All new declarations and cases will be root-imported and audited with fixed Lean4.33.1/core; no project axioms or sorry.

Source initial and code-only explanation are independent roles. Initial coding model tests may precede fidelity acceptance, but published passed/limited states require the recorded corresponding review. New model tradeoff: intentionally small exact worked fragments for readers instead of importing large legacy interfaces with stale provenance; report reduced retained proof coverage, not a formalization improvement by line count.
