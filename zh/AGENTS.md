# 中文翻译规则

本文件仅约束 `zh/` 下的中文翻译文件。英文哲学正本及英文配套文档是翻译基准：[英文哲学正本](../PHILOSOPHY.md)与[英文论证](../rationale/README.md)分别规定相应文本的含义、条件与限度；出现差异时，以英文文本为准。产品运行工具不依赖第三方运行库。站点构建与验证可使用锁定的第三方依赖；这些依赖不进入安装包。

中文翻译须与英文文本保持相同的含义、义务或确定性强度、条件、范围及必要限定，同时允许自然的中文措辞差异。术语、指代和适用范围须保持一致；表达应语法正确、精确、简洁且无歧义。不得因追求简短而删除必要条件，也不得加入英文没有支持的义务或确定性。

处理 `zh/` 下的翻译时，建议在 subagent 可用且任务适合独立处理时，将翻译交给使用独立任务上下文的 subagent，以减少翻译过程占用主任务上下文。为其提供必要的对应英文基准、现有译文、本文件规则，以及相关术语和变更范围；由其返回修改摘要与未决问题，主代理负责核对译文及同步结果。小范围修改或 subagent 不可用时，可由主代理直接处理。翻译委派不替代独立审查。

对应的英文和中文文件应同步更新。翻译规则不扩展为一般哲学义务，也不取代根目录的维护流程、独立审查、用户决定或验证要求。

## Lean 对照稿

`zh/lean/` 翻译对应英文 `lean/` 的读者稿。逐主张速览与逐行详解必须保留同一来源、版本、声明及判定范围；Lean 代码、标识符、hash 和机器状态标记保持原样，解释文字使用中文。逐行稿覆盖英文稿中每个非空代码行，不以语法概述替代具体证明步骤和假设。

分别保留 Lean 检查结果、来源保真判断与汇总状态。不得把有限度通过译成完整通过，把未完成或支持不足译成原文为假，或把反模型检查成功译成受反驳推论通过。保留未完成、不适用、过期及失败原因。发现英文解释与代码或证据不符时返回该问题，不通过译文自行修复或升级判断；中文翻译不构成新的独立盲评。

Core 内的 Lean 工程、证据与读者稿按[根目录维护规则](../AGENTS.md#lean-evidence-maintenance)同步。正文、rationale、来源版本、编码、假设或相关工具／技能行为改变时，核对受影响的两种粒度和审查对象；未完成必要复核与翻译同步前，不宣称相关维护已完成。无关变更不要求重做全部保真审查。历史稿保留其冻结来源与历史判定，不冒充当前有效版本；仅迁移路径时须明确说明未变内容及复用依据。

当前稿保留核心哲学对象；此前的 rationale 独立工程和读者稿已归档。稳定路径不代表不可变的证据身份。替换前将旧对象的完整引用闭包归档到被忽略的 `.local/`，包括运行目录以外的读者稿，并在独立副本验证历史复跑。正式 Lean 交付仅包含当前对象及其必要证据；使用和测试不得依赖本地历史。新执行记录中的工具 hash 与运行时版本只说明执行身份，不证明工具已获认可；按实际影响复核，不给历史记录追补新身份或新批准。

速览可将结构和空白条目集中紧凑呈现，但每项的精确摘录、独立边界、标识和状态仍须保留。完整上下文、代码、依赖及逐行解释放在详解。不得将登记条目省略误作阅读优化；用实际定位与理解任务检查改进，行数减少本身不是能力提升的证据。
