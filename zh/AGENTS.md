# 中文翻译规则

本文件仅约束 `zh/` 下的中文翻译文件。英文哲学正本及英文配套文档是翻译基准：[英文哲学正本](../PHILOSOPHY.md)与[英文论证](../docs/rationale.md)分别规定相应文本的含义、条件与限度；出现差异时，以英文文本为准。

中文翻译须与英文文本保持相同的含义、义务或确定性强度、条件、范围及必要限定，同时允许自然的中文措辞差异。术语、指代和适用范围须保持一致；表达应语法正确、精确、简洁且无歧义。不得因追求简短而删除必要条件，也不得加入英文没有支持的义务或确定性。

处理 `zh/` 下的翻译时，建议在 subagent 可用且任务适合独立处理时，将翻译交给使用独立任务上下文的 subagent，以减少翻译过程占用主任务上下文。为其提供必要的对应英文基准、现有译文、本文件规则，以及相关术语和变更范围；由其返回修改摘要与未决问题，主代理负责核对译文及同步结果。小范围修改或 subagent 不可用时，可由主代理直接处理。翻译委派不替代独立审查。

对应的英文和中文文件应同步更新。翻译规则不扩展为一般哲学义务，也不取代根目录的维护流程、独立审查、用户决定或验证要求。
