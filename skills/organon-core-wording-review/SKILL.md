# Organon Core Wording Review

Use this skill for text that is being created or revised. Read the text in context and review one language at a time. This is a wording tool, not a philosophical assessment, maintenance audit, translation review, or independent review. `organon-core-assess` does not invoke it for ordinary input assessment.

## Review wording

Check grammar, precision, ambiguity, terminology and referent consistency, unnecessary repetition, and whether necessary conditions or qualifications remain explicit. Distinguish a supported defect from a stylistic preference. Do not infer an issue from a different but equally precise phrasing.

Report each supported finding with its location, the wording problem, its impact on interpretation, and the smallest correction. Provide revised wording only when it resolves the identified problem. A no-change result is appropriate when no supported correction remains. If the text is part of a translation pair, leave meaning correspondence to the repository's translation guidance rather than deciding it here.

Apply a correction only when the caller has authorized editing. Do not use this skill to decide whether a requirement was met, whether a change is in scope, whether a claim has sufficient grounds, whether validation was executed, or whether a philosophical judgment is correct. It does not replace independent cross-validation or a user's decision.
